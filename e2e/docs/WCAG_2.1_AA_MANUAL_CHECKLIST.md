# WCAG 2.1 Level AA – Optional Manual Reference (N/A criteria only)

**The certifiable suite is fully automated.** Certification is based on automated results only; this checklist is **not required** for certification.

If you want to verify **N/A criteria** (those the suite cannot automate) for internal or compliance review, you can use this as an optional reference. Mark ✅ when verified; N/A when the criterion does not apply.

See [WCAG_2.1_AA_MAPPING.md](./WCAG_2.1_AA_MAPPING.md) for which criteria are automated vs N/A.
